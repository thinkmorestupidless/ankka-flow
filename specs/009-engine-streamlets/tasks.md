# Tasks: Engine Streamlets

**Input**: Design documents from `/specs/009-engine-streamlets/`

**Prerequisites**: [plan.md](./plan.md), [spec.md](./spec.md), [research.md](./research.md),
[data-model.md](./data-model.md), [contracts/](./contracts/), [quickstart.md](./quickstart.md);
the scenarios are in `features/pipelines/*.feature` and three in `features/cli/`.

**Tests**: included, first where a test can be written before the thing it holds.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel — different files, no dependency on an incomplete task
- **[Story]**: US1 (Pekko Streams), US2 (Flink), US3 (one blueprint, several engines), US4 (ankka
  topics), US5 (which to choose), US6 (version one removed)

`PKG` = `com/thinkmorestupidless/ankka/flow`. `DESC` = `descriptor/src/main/scala/PKG/descriptor`,
`DESCT` its `src/test` twin. `PEKKO` = `sdks/pekko-streams/src/main/scala/PKG/pekko`, `PEKKOT` its
test twin. `FLINK` = `sdks/flink/src/main/java/PKG/flink`, `FLINKT` its test twin. `KIT` =
`sdks/flink-testkit/src/main/java/PKG/flink/testkit`. `BP`, `CRD`, `OP`, `CLI` = the main Scala
directory of `blueprint`, `crd`, `operator`, `cli`; `BPT`, `CRDT`, `OPT`, `CLIT` their test twins.
`SAMPLE` = `samples/cart-pipeline`. "R*n*" is a section of `research.md`, "V*n*" an item of its
*Verify first* list, "C:*name*" a file of `contracts/`.

Every task ends green on what it names. A task that finds a contract must change stops and asks.

## Implementation strategy

MVP is Phases 1 to 3: a Pekko Streams streamlet end to end, which already proves a streamlet that owns its own reading and writing. Phase 4 adds the capability the project returned for; Phase 5 shows the seam is in the right place. Stop and validate at each checkpoint. Phases 6 to 8 follow in order. Each phase ends with a commit that leaves `sbt -Dflow.cluster.tests=off test`, `just features` and, from Phase 7, `just docs` green; between Phase 2 and Phase 7 `just docs` is expected to report the pages that still describe version one, and that is not a failure of those phases.
