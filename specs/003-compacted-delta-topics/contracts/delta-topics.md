# Contract: delta topics in the CLI and the operator

A **delta topic** is a topic with at least one port, producing or consuming, of
`ankka.graph-delta.v1`.

## `flow verify` and `flow generate`

For each delta topic, one note on stderr (the exit code is unchanged):

| case | note |
|---|---|
| managed, no `cleanup.policy` in the blueprint or `--conf` | `note: Topic '<id>' carries graph deltas and is compacted (cleanup.policy = compact).` |
| managed, `cleanup.policy = compact` set | the same note |
| managed, `cleanup.policy = compact,delete` | `note: Topic '<id>' carries graph deltas and sets cleanup.policy = compact,delete; records older than its retention are gone from a rebuild.` |
| managed, a policy without `compact` | `note: Topic '<id>' carries graph deltas and sets cleanup.policy = <p>; it will not hold the whole graph and cannot be relied on to rebuild it.` |
| unmanaged | `note: Topic '<id>' carries graph deltas and is not managed; whether it is compacted is its owner's.` |

`flow generate` writes `cleanup.policy: compact` into the topic's `topicConfig` in the first case
and leaves the others as set. A topic that is not a delta topic is written exactly as before.

A blueprint sets a policy as any topic setting:

```hocon
graph-deltas { producers = [mapper.deltas], consumers = [graph.in], topic { cleanup.policy = "compact,delete", retention.ms = 2592000000 } }
```

and `--conf` overrides it: `flow.topics.graph-deltas { topic { cleanup.policy = delete } }`. A policy
naming both must be quoted, as above: an unquoted comma ends the field in HOCON.

## The operator

- Creates a missing managed topic with the resource's `topicConfig`, as it does today; a delta
  topic generated by this CLI is therefore created compacted.
- For an existing topic whose `cleanup.policy` does not include `compact` while the resource's
  does: records `TopicNotCompacted` (Warning) and changes nothing:

  ```text
  topic 'checkouts-graph.graph-deltas' exists and is not compacted (cleanup.policy = delete); the resource asks for compact. Left as it is: it will not hold the whole graph. To compact it, alter or recreate the topic.
  ```

  `cleanup.policy` is then not repeated under `TopicSettingsIgnored`. (A topic that has
  `compact,delete` when the resource asks for `compact` is compacted, so it draws no
  `TopicNotCompacted`; the differing value is listed under `TopicSettingsIgnored` as any other.)
- Never alters, deletes or writes to a topic on account of this feature.
